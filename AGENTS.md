# Правила работы с проектом

## Обязательное сопровождение документации

- При каждом изменении проекта обновляйте `docs/CHANGELOG.md`, указывая дату и кратко описывая сделанное.
- При каждом изменении проекта проверяйте и актуализируйте `docs/PROJECT.md`, чтобы в нём оставалось точное описание текущих возможностей и устройства приложения.
- Сохраняйте каждый новый пользовательский промпт в `docs/PROMPTS.md` при выполнении соответствующего запроса; не изменяйте текст прежних записей.
- После успешных проверок сохраняйте изменения проекта в настроенном GitHub-репозитории; никогда не публикуйте локальный `.env` или иные секреты.
- Если меняются запуск, настройки или пользовательские инструкции, обновляйте также корневой `README.md`.
- Документация должна описывать реализованное поведение, а не планы или неподтверждённые свойства.

## Работа с кодом

- Перед изменением изучите соответствующий участок кода и связанные тесты. Сохраняйте существующий стиль CommonJS и простую архитектуру приложения.
- Не добавляйте зависимости без необходимости. Для стандартных проверок используйте `npm test`.
- Не изменяйте `data/pages.json` и `data/uploads/`: это содержимое сайта, а не исходный код. Меняйте его только по прямой просьбе пользователя.
- Сохраняйте серверную очистку и экранирование HTML, проверку CSRF, аутентификацию администратора и валидацию загружаемых файлов. Не ослабляйте эти защиты ради удобства.
- Добавляйте или обновляйте тесты для изменений поведения и проверяйте, что связанные тесты проходят.
- Не исправляйте несвязанные проблемы и не удаляйте пользовательские данные или существующие изменения.

## Полезные команды

- Установка зависимостей: `npm install`
- Запуск: `npm start`
- Тесты: `npm test`

Для запуска скопируйте `.env.example` в `.env` и задайте `ADMIN_USERNAME` и `ADMIN_PASSWORD`; пароль должен содержать не менее 12 символов. Приложение загружает `.env` автоматически, а файл с секретами должен оставаться вне Git.

## Документация проекта

- `README.md` — запуск и использование сайта.
- `docs/PROJECT.md` — возможности, структура и технические ограничения.
- `docs/CHANGELOG.md` — журнал выполненных изменений.
- `docs/PROMPTS.md` — архив доступных пользовательских запросов по проекту.
