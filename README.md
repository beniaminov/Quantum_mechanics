# Многостраничный сайт

Многостраничный сайт на Node.js с админ-панелью для управления страницами. Администратор может редактировать HTML визуальным редактором, создавать и удалять страницы, загружать изображения и PDF. Содержимое сохраняется в `data/pages.json`, вложения — в `data/uploads/`. Проект работает без Jupyter, Docker и Python.

## Требования и запуск

Требуется Node.js 18 или новее. Установите зависимости и создайте локальный файл `.env` из шаблона. Укажите в нём имя администратора и пароль длиной не менее 12 символов, затем запустите сайт:

```powershell
npm install
Copy-Item .env.example .env
# Откройте .env и задайте собственный пароль
npm start
```

Сервер автоматически загружает `.env`; переменные, уже заданные в окружении, имеют приоритет. Локальный `.env` исключён из Git. Откройте `http://localhost:3000/`. Сервер по умолчанию слушает `0.0.0.0:3000`; это адрес привязки, а не адрес для браузера. Порт и интерфейс можно изменить через `PORT` и `HOST`.

## Возможности

- Публичные страницы с меню; главная показывает дату и время на момент загрузки.
- Страницы [обзора исследовательского проекта](/unification) и [фазового пространства и декогеренции](/phase-space), подготовленные по исходному PDF.
- Админ-панель `/admin`: вход, создание, редактирование и удаление страниц (главную удалить нельзя), изменение порядка страниц перетаскиванием или кнопками перемещения.
- Визуальный HTML-редактор: форматирование текста, внутренние ссылки, просмотр и редактирование HTML-кода.
- Загрузка и вставка изображений и PDF; настройка размера изображений.
- MathJax для локального отображения LaTeX-формул.
- Серверная очистка HTML и проверка загружаемых файлов.

Для входа перейдите на `/admin` и используйте учётные данные из `.env` или окружения. Сессии действуют до 8 часов и хранятся в памяти процесса.
