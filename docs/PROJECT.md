# О проекте

## Назначение

Это небольшой многостраничный сайт с административной панелью для управления содержимым и вложениями. HTTP-сервер реализован на Node.js с использованием `node:http`. Проект не требует Jupyter, Docker или Python.

## Возможности

- Публичные страницы с меню навигации; главная показывает текущие дату и время при загрузке.
- Вход администратора, редактирование страниц визуальным HTML-редактором, создание страниц и удаление страниц кроме главной.
- Форматирование текста, ссылки на внутренние страницы и разрешённые внешние адреса, вставка изображений и PDF, изменение размера изображений.
- Локальный MathJax для отображения LaTeX-формул.
- Две публичные обзорные страницы об авторском проекте объединения квантовой и классической механики; на подробной странице доступен исходный PDF.
- До четырёх вложений на страницу, размер каждого файла — до 5 МБ. Поддерживаются PNG, JPEG, GIF, WebP и PDF; фактический тип файла проверяется по сигнатуре.
- Очистка HTML на сервере перед сохранением и выводом.
- Состояние сервиса доступно через `GET /health`.

## Структура и хранение данных

- `my_hello.js` — HTTP-сервер, маршрутизация, проверка запросов, хранение страниц и рендеринг.
- `public/admin-editor.js` — клиентская логика редактора.
- `public/mathjax-config.js` — конфигурация MathJax.
- `data/pages.json` — заголовки, содержимое и метаданные вложений страниц.
- `data/uploads/` — загруженные изображения и PDF.
- `ProjectQMandCM.pdf` — исходный документ, по которому подготовлены страницы `/unification` и `/phase-space`; копия PDF доступна посетителям как вложение страницы.
- `my_hello.test.js`, `my_hello.regressions.test.js` — автоматические тесты.
- `package.json` и `package-lock.json` — команды проекта и зависимость MathJax.

Страницы хранятся в JSON; обновление файла выполняется через временный файл и переименование. Файлы вложений лежат отдельно от метаданных. Сессии администратора хранятся в памяти и истекают после восьми часов; после перезапуска сервера нужно войти снова.

## Основные маршруты

| Маршрут | Назначение |
| --- | --- |
| `/` и `/<slug>` | Публичная главная страница и страницы сайта |
| `/admin/login` | Вход администратора |
| `/admin` | Список страниц и создание страницы |
| `/admin/pages/<slug>` | Редактирование страницы и управление вложениями |
| `/admin/pages/<slug>/delete` | Удаление страницы |
| `/unification` | Обзор авторского проекта объединения квантового и классического описаний |
| `/phase-space` | Подробности фазового пространства, модели и направлений дальнейшей работы |
| `/uploads/<id>` | Выдача сохранённого вложения |
| `/mathjax/...` | Выдача локальных ресурсов MathJax |
| `/health` | Проверка состояния сервиса |

## Запуск и проверки

Требуется Node.js 18 или новее. Установите зависимости командой `npm install`, задайте переменные окружения `ADMIN_USERNAME` и `ADMIN_PASSWORD` (пароль — не менее 12 символов), затем запустите `npm start`. Для проверки изменений используйте `npm test`.

Подробные инструкции находятся в корневом `README.md`.

## Ограничения и безопасность

- Хранилище JSON и сессии в памяти подходят для небольшого сайта, но не заменяют базу данных и постоянное хранилище сессий для масштабного развертывания.
- Для публичного развертывания используйте HTTPS и храните пароль в защищённых переменных окружения.
- Пользовательский HTML очищается на сервере; не обходите очистку при добавлении редакторских возможностей.
- Не публикуйте секреты и не изменяйте пользовательские данные страниц или загруженные файлы без соответствующего запроса.
