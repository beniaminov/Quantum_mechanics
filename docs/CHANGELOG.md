## 2026-10-21 — Локальная установка JupyterLab

- Добавлены `requirements-jupyter.txt` и кроссплатформенная команда `npm run jupyter`; Jupyter слушает только localhost и использует `data/notebooks/`.
- Настроен локальный URL Jupyter по умолчанию для обычного `npm start`, чтобы админка не показывала сообщение «JupyterLab не настроен», если переменная среды не задана.
- Обновлён README: пошаговый запуск сайта и JupyterLab в двух окнах, процесс входа и сохранения, загрузка изображений и удалённое развертывание через Docker Compose.
